# Day 3 Mini-Project

## Project

Build a simple DevOps countdown and status checker in `project.py`.

## Idea

Pretend a deployment starts in 5 steps. Your script should:

- count down from 5 to 1
- print a message at each step
- print `"Deployment started"` at the end

## Stretch Option

Add a second loop that prints all even-numbered server IDs from 2 to 10.

## Goal

Keep the script readable. You are practicing repetition and loop control.
