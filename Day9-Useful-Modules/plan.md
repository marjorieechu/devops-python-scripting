# Day 9 Plan

## Focus

Learn how to use common Python modules for file paths, folders, JSON, and CSV.

## Time Split

- 20 minutes: read `learn.md`
- 50 minutes: complete `exercise.py`
- 20 minutes: complete `project.py`, test outputs, and update `notes.md`

## Goal

By the end of Day 9, you should be able to:

- list files in a folder
- use `pathlib.Path`
- write JSON data to a file
- read a CSV file
- inspect file names, extensions, and sizes
