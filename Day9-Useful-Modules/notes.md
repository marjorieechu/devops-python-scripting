## My Notes
A `module` is a file containing code that can be reused/imported in another script. its a passage to recall or reuse a file in a script.
Built-in python modules(or libraries)  like json, os, csv, pathlib provide ready made functionality so codes are not written from scratch rather can be reused.

import module usually loads the module or tool to handle the content file.
`iterdir()` is a method from pathlib that lists all items in a folder (directory).
