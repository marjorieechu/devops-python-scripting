# Day 1 to Day 3 Revision Tasks

Use this before moving to Day 4.

Rule:
- Write each task as a small Python script.
- Keep each script short.
- Run every script after writing it.
- If possible, explain the output in plain English after each one.

## Day 1: Variables and Output

### `print()`

1. Write a script that prints your name.
2. Write a script that prints your favorite food, color, and city on 3 separate lines.
3. Write a script that prints `"Python practice day 1"` exactly as written.
4. Write a script that prints 3 DevOps words, one per line.
5. Write a script that prints a welcome message and a goodbye message.

### Variables

1. Create a variable called `name` and store your name in it, then print it.
2. Create variables for `country`, `job`, and `tool`, then print all 3.
3. Create a variable called `score`, give it a number, then print it.
4. Create a variable called `server_name` and print `Server: <value>`.
5. Create 4 variables about yourself and print them one after another.

### Strings

1. Store `"Hello, Python"` in a variable and print it.
2. Create a variable called `cloud_tool` and assign text to it.
3. Store your favorite command in a string and print it.
4. Create 3 string variables and print them in separate lines.
5. Create a string variable called `message` and change its value before printing again.

### Numbers

1. Create a variable `age` and print it.
2. Create `current_year` and `birth_year`, then subtract to estimate your age.
3. Create `x = 10` and `y = 5`, then print their sum.
4. Create a variable `hours = 2` and print how many minutes that is.
5. Create `servers = 4`, add 3 more, and print the result.

### Comments

1. Write a script with one comment explaining what the script does.
2. Add comments above 3 variables to explain each one.
3. Write a small script with comments and output, then run it.
4. Add a comment before a calculation that explains the math.
5. Take an old Day 1 script and improve it by adding useful comments.

### F-strings

1. Create a variable `name` and print `My name is ...` with an f-string.
2. Create `age` and print `I am ... years old` with an f-string.
3. Create `tool = "Docker"` and print a sentence using it with an f-string.
4. Create `current_age` and `future_age`, then print both in one f-string sentence.
5. Create 4 variables about yourself and print one clean introduction using f-strings.

## Day 2: Conditions and Decisions

### `if`

1. Create `age = 20` and print `"Adult"` if age is 18 or more.
2. Create `score = 80` and print `"Pass"` if score is 50 or more.
3. Create `temperature = 35` and print `"Hot"` if it is greater than 30.
4. Create `is_logged_in = True` and print `"Access granted"` if true.
5. Create `battery = 15` and print `"Low battery"` if it is below 20.

### `elif`

1. Create `score` and print `"Excellent"`, `"Pass"`, or `"Fail"` using `if/elif/else`.
2. Create `hour` and print `"Morning"`, `"Afternoon"`, or `"Night"`.
3. Create `temperature` and print `"Cold"`, `"Warm"`, or `"Hot"`.
4. Create `service_status_code` and print messages for `200`, `404`, and other values.
5. Create `age` and print `"Child"`, `"Teen"`, or `"Adult"`.

### `else`

1. Create `password = "admin123"` and print `"Correct"` or `"Wrong"`.
2. Create `number = 7` and print whether it is even or odd.
3. Create `has_ticket = False` and print `"Enter"` or `"No entry"`.
4. Create `disk_space = 60` and print `"Enough space"` or `"Low space"`.
5. Create `username = ""` and print `"Username provided"` or `"Username is empty"`.

### Booleans

1. Create a variable `is_admin = True` and print it.
2. Create `has_access = False` and print it.
3. Compare `5 > 2` and store the result in a boolean variable, then print it.
4. Create a script that prints the result of `10 == 10` and `10 != 8`.
5. Create `is_active = True` and use it in a small `if` statement.

### Comparison Operators

1. Print the result of `5 == 5`.
2. Print the result of `9 != 3`.
3. Print the result of `7 > 10`.
4. Print the result of `15 <= 15`.
5. Create 2 variables and compare them with `>`, `<`, and `==`.

## Day 3: Loops and Repetition

### `for`

1. Use a `for` loop to print numbers 1 to 5.
2. Use a `for` loop to print your name 3 times.
3. Use a `for` loop to print even numbers from 2 to 10.
4. Use a `for` loop to print 5 server names like `server-1` to `server-5`.
5. Use a `for` loop to print numbers from 10 down to 1.

### `while`

1. Use a `while` loop to print numbers 1 to 5.
2. Use a `while` loop to count down from 5 to 1.
3. Use a `while` loop to print `"Retrying..."` 3 times.
4. Use a `while` loop to print even numbers from 2 to 10.
5. Use a `while` loop to print numbers from 1 to 10 and stop when the condition becomes false.

### `range()`

1. Print numbers from `range(5)`.
2. Print numbers from `range(1, 6)`.
3. Print even numbers using `range(2, 11, 2)`.
4. Print odd numbers from 1 to 9 using `range()`.
5. Print numbers from 20 down to 0 using a negative step in `range()`.

### Counters

1. Create `count = 1` and increase it until 5 with a `while` loop.
2. Create `count = 5` and decrease it to 1.
3. Count how many times a loop runs from 1 to 10.
4. Use a counter to total numbers from 1 to 5.
5. Use a counter in a loop to print `Attempt 1`, `Attempt 2`, `Attempt 3`.

## Suggested Order

1. Start with all Day 1 tasks.
2. Move to Day 2 after your output and variables feel easy.
3. Finish with Day 3 and rerun any task that felt weak.

## Minimum Strong Revision Target

If you do not want to do all tasks at once, complete at least:

- 3 tasks from each Day 1 section
- 3 tasks from each Day 2 section
- 3 tasks from each Day 3 section

That still gives you strong revision before Day 4.
