# Day 1 to Day 3 Revision Tasks

Use this before moving to Day 4.

Rule:
- Write each task as a small Python script.
- Keep each script short.
- Run every script after writing it.
- If possible, explain the output in plain English after each one.

## Day 1: Variables and Output

### `print()`

1. Write a script that prints your name.
2. Write a script that prints your favorite food, color, and city on 3 separate lines.

### Variables

1. Create a variable called `name` and store your name in it, then print it.
2. Create variables for `country`, `job`, and `tool`, then print all 3.

### Strings

1. Store `"Hello, Python"` in a variable and print it.
2. Create a variable called `cloud_tool` and assign text to it.

### Numbers

1. Create a variable `age` and print it.
2. Create `current_year` and `birth_year`, then subtract to estimate your age.

### Comments

1. Write a script with one comment explaining what the script does.
2. Add comments above 3 variables to explain each one.

### F-strings

1. Create a variable `name` and print `My name is ...` with an f-string.
2. Create `age` and print `I am ... years old` with an f-string.

## Day 2: Conditions and Decisions

### `if`

1. Create `age = 20` and print `"Adult"` if age is 18 or more.
2. Create `score = 80` and print `"Pass"` if score is 50 or more.

### `elif`

1. Create `score` and print `"Excellent"`, `"Pass"`, or `"Fail"` using `if/elif/else`.
2. Create `hour` and print `"Morning"`, `"Afternoon"`, or `"Night"`.

### `else`

1. Create `password = "admin123"` and print `"Correct"` or `"Wrong"`.
2. Create `number = 7` and print whether it is even or odd.

### Booleans

1. Create a variable `is_admin = True` and print it.
2. Create `has_access = False` and print it.

### Comparison Operators

1. Print the result of `5 == 5`.
2. Print the result of `9 != 3`.

## Day 3: Loops and Repetition

### `for`

1. Use a `for` loop to print numbers 1 to 5.
2. Use a `for` loop to print your name 3 times.

### `while`

1. Use a `while` loop to print numbers 1 to 5.
2. Use a `while` loop to count down from 5 to 1.

### `range()`

1. Print numbers from `range(5)`.
2. Print numbers from `range(1, 6)`.

### Counters

1. Create `count = 1` and increase it until 5 with a `while` loop.
2. Create `count = 5` and decrease it to 1.

## Suggested Order

1. Start with all Day 1 tasks.
2. Move to Day 2 after your output and variables feel easy.
3. Finish with Day 3 and rerun any task that felt weak.

## Minimum Strong Revision Target

If you do not want to do all tasks at once, complete at least:

- 2 tasks from each Day 1 section
- 2 tasks from each Day 2 section
- 2 tasks from each Day 3 section

That still gives you strong revision before Day 4.
