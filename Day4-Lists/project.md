# Day 4 Mini-Project

## Project

Build a simple task list manager in `project.py`.

## Idea

Pretend you are tracking a small DevOps work queue. Your script should:

- start with 3 tasks
- add 2 more tasks
- print all tasks with numbers

## Stretch Option

Add a section that:

- removes one completed task
- prints the updated task list
- shows how many tasks are still left

## Goal

Keep the script readable. You are practicing storing values in lists and looping through them.
