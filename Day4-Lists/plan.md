# Day 4 Plan

## Goal

Learn how to store and manage groups of values in Python using:

- lists
- indexing
- slicing
- `.append()`
- `.remove()`
- loops with lists

## Time Split

1. 20 minutes: read `learn.md`
2. 50 minutes: complete `exercise.py`
3. 20 minutes: complete `project.py` and update `notes.md`

## Output For Today

By the end of Day 4, you should be able to:

- create a list and read values from it
- access the first and last item in a list
- add and remove items
- loop through a list one item at a time
- explain what a slice like `my_list[1:3]` means
