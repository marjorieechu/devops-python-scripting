# Day 4 Exercise

## Task

Edit `exercise.py` so it:

- stores 5 fruits in a list
- prints the first fruit
- prints the last fruit
- adds one fruit
- removes one fruit
- prints all fruits one by one

## Extra Practice

After it works:

- sort the list
- print how many items are in the list
- print a slice that shows the middle fruits

## Questions

When you finish, answer:

1. What index is the first item in a list? 0
2. What does `my_list[-1]` mean? last item in the list
3. What does `my_list[1:3]` return? the second and third items in the list
