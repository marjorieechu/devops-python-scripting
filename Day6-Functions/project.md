# Day 6 Mini-Project

## Task

Build a small server helper script in `project.py`.

## Requirements

Create functions for:

- showing a server greeting
- checking whether CPU usage is safe
- adding two storage values
- formatting one status report line

## Example Idea

Your script can work with values like:

- server name
- CPU usage
- used storage
- free storage

## Output

Print a short readable report using your functions.
