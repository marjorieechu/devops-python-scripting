# Day 5 Mini-Project

## Project

Build a simple server profile tracker in `project.py`.

## Idea

Pretend you are tracking one server in a DevOps environment. Your script should:

- store the server name, IP address, status, and roles in a dictionary
- store contact info in a nested dictionary
- print the details in a readable format

## Stretch Option

Add a section that:

- uses `.get()` to read a missing field
- updates the server status
- prints the updated dictionary data

## Goal

Keep the script readable. You are practicing storing labeled data in dictionaries.
