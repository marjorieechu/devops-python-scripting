# Day 4 to Day 10 Revision Tasks

Use this before moving deeper into later scripting topics.

Rule:
- Write each task as a small Python script.
- Keep each script short.
- Run every script after writing it.
- If possible, explain the output in plain English after each one.

## Day 4: Lists

### Creating Lists

1. Create a list of 5 fruits and print it.
2. Create a list of 4 cloud tools and print it.

### Indexing

1. Print the first item in a list of fruits.
2. Print the last item in a list of tools.

### Slicing

1. Print the first 2 items in a list.
2. Print the last 2 items in a list.

### List Methods

1. Create a list and add one new item with `.append()`.
2. Create a list and remove one item with `.remove()`.

### Looping Through Lists

1. Loop through a fruit list and print each fruit.
2. Loop through a tool list and print each item on a new line.

## Day 5: Dictionaries

### Key-Value Pairs

1. Create a dictionary with your name, age, and city.
2. Create a dictionary for a server with name, IP, and status.

### Accessing Values

1. Print the `name` from a dictionary.
2. Print the `status` from a server dictionary.

### `.get()`

1. Use `.get()` to read a value from a dictionary.
2. Use `.get()` on a missing key and print the result.

### Nested Dictionaries

1. Create a dictionary with nested `contact` information.
2. Create a server dictionary with nested `owner` details.

## Day 6: Functions

### Defining Functions

1. Write a function that prints `Hello`.
2. Write a function that prints your name.

### Parameters

1. Write a function that greets a user by name.
2. Write a function that prints a tool name passed to it.

### Return Values

1. Write a function that adds 2 numbers and returns the result.
2. Write a function that returns your full name.

### Local Variables

1. Write a function with a local variable and print it inside the function.
2. Create a local variable called `message` inside a function.

## Day 7: Files

### Reading Text Files

1. Create a text file and read its full content.
2. Create a text file with 3 lines and print them.

### Writing Text Files

1. Write one line into a new text file.
2. Write 3 lines into a text file.

### JSON

1. Save a dictionary into a JSON file.
2. Read a JSON file back and print the dictionary.

## Day 8: Errors and Exceptions

### `try/except`

1. Ask for a number and handle invalid input.
2. Try converting text to `int` and catch the error.

### Common Errors

1. Trigger a `ValueError` and handle it.
2. Trigger a `ZeroDivisionError` and handle it.

### Safe Input Handling

1. Ask for age and convert it safely to `int`.
2. Ask for 2 numbers and add them with error handling.

## Day 9: Useful Modules

### `os`

1. Use `os.listdir()` to print items in the current folder.
2. Use `os.listdir()` on another folder path.

### `pathlib`

1. Create `Path(".")` and print it.
2. Print the absolute path using `.resolve()`.

### `json`

1. Save a small dictionary to `data.json`.
2. Read `data.json` back and print it.

### `csv`

1. Read `sample.csv` and print each row.
2. Count how many rows are in a CSV file.

## Day 10: String Processing

### Cleaning Strings

1. Create a messy sentence and clean it with `.strip()`.
2. Replace one word in a sentence with `.replace()`.

### Splitting and Counting

1. Split a sentence into words and print the list.
2. Count the number of words in a sentence.

### Searching Inside Strings

1. Check whether `"ERROR"` is in a log line.
2. Check whether `"INFO"` is in a log line.

## Suggested Order

1. Start with Day 4 and make sure list operations feel easy.
2. Move through Day 5 and Day 6 carefully because dictionaries and functions are core scripting tools.
3. Use Day 7 to Day 10 as practical revision for files, errors, modules, and string processing.
