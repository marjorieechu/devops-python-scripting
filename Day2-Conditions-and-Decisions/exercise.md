# Day 2 Exercise

## Task

Edit `exercise.py` so it:

- stores a number in `score`
- prints `"pass"` if score is 50 or more
- prints `"fail"` if score is less than 50
- prints `"excellent"` if score is 85 or more

## Extra Practice

After it works:

- change the score 3 times
- confirm the output changes correctly

Suggested test values:

- 40
- 65
- 90

## Questions

When you finish, answer:
