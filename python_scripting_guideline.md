# Python Scripting 14/21-Day Guideline

Start on Saturday, March 14, 2026. At 1.5 hours/day, that gives you 21 focused hours, which is enough to get very solid at Python scripting if you stay practical.

## Approach

Do not start with "Python theory." Start with scripts.

Every day, split your 90 minutes like this:

1. 20 min: learn one small concept
2. 50 min: write a script using it
3. 20 min: debug, clean up, and explain what the script does in plain English

Use only local scripts first. Avoid Lambda, frameworks, web apps, and advanced OOP for now.

## What To Learn

- Day 1: `print`, variables, strings, numbers, comments
- Day 2: `if`, `elif`, `else`, comparisons, booleans
- Day 3: loops: `for`, `while`, `range`
- Day 4: lists, indexing, slicing, basic methods
- Day 5: dictionaries, nested data, `.get()`
- Day 6: functions, parameters, return values
- Day 7: file handling: read/write `.txt`, `.json`
- Day 8: exceptions: `try/except`, common errors
- Day 9: modules: `os`, `pathlib`, `json`, `csv`
- Day 10: string processing and parsing text
- Day 11: working with APIs using `requests`
- Day 12: automation scripts: rename files, summarize logs, clean CSVs
- Day 13: build a full mini-project
- Day 14: rebuild the project from scratch without notes

## Best Mini-Projects

Pick one per day:

- Rename files in a folder
- Parse a log file and count errors
- Read a CSV and filter rows
- Convert JSON to a cleaner format
- Backup files from one folder to another
- Check whether files exist and report missing ones
- Call a public API and save results to JSON
- Generate a simple report from text or CSV

## What Great Python Scripters Are Actually Good At

- Breaking a task into small steps
- Reading docs and error messages
- Using lists/dicts comfortably
- Handling files and data formats
- Writing functions instead of giant scripts
- Debugging fast

That is the bar you should target in 2 weeks, not "master Python."

## Rules

- Type every script yourself
- Do not copy large tutorials blindly
- Keep each script under 100 lines at first
- After each script, refactor once
- Keep a `notes.md` with errors you hit and how you fixed them

## Your Stack

Install and use:

- Python 3.12+
- VS Code
- `venv`
- `pip`
- `requests`

Learn these commands early:

```bash
python --version
python script.py
python -m venv .venv
.venv\Scripts\activate
pip install requests
```
