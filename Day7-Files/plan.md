# Day 7 Plan

## Focus

Learn how to read from files, write to files, and work with JSON data.

## Time Split

- 20 minutes: read `learn.md`
- 50 minutes: complete `exercise.py`
- 20 minutes: complete `project.py`, review outputs, and update `notes.md`

## Goal

By the end of Day 7, you should be able to:

- open files in read mode and write mode
- read text from a file
- count lines in a file
- write a summary to another file
- save and load a dictionary with JSON
