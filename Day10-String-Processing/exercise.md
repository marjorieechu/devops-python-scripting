# Day 10 Exercise

## Task

Complete `exercise.py`.

## Requirements

Your script should:

- clean a messy sentence
- count words
- find how many times a word appears

## Stretch

- remove extra spaces
- normalize mixed capitalization

## Questions

When you finish, answer:

1. Why do scripts often spend a lot of time on strings?
2. What is the difference between `.strip()` and `.replace()`?

Answers:
1. Scripts spend a lot of time on strings because files, logs, user input, and API data often come in text form.
2. .strip() removes characters from the start and end of a string, while .replace() changes matching text anywhere in the string.
