# Day 10 Plan

## Focus

Learn how to clean, search, and count text using Python string methods.

## Time Split

- 20 minutes: read `learn.md`
- 50 minutes: complete `exercise.py`
- 20 minutes: complete `project.py`, test outputs, and update `notes.md`

## Goal

By the end of Day 10, you should be able to:

- clean messy text
- split a sentence into words
- count words
- search for a word inside text
- process simple log lines from a file
